# Kakao Message Filter · Windows / Android

카카오톡 PC 채팅창에서 지정한 닉네임의 **사진·말풍선·연속 메시지 그룹** 위에 클릭이 통과되는 가림막을 표시합니다. Python 3.11 이상, Win32 API, Tesseract OCR, OpenCV를 사용합니다. 서버 메시지나 카카오톡 내부 파일은 수정하지 않습니다.

**실험 단계입니다. 실제 카카오톡에서의 정확도는 아직 검증하지 않았습니다.** Linux 클라우드에서는 실제 한국어/영어 OCR과 필터 로직을 검사했습니다. Windows 캡처·클릭 통과·배율·창 전환은 실제 PC 검증이 필요합니다. Android는 포함하지 않습니다.

## 긴 말풍선과 스크롤 지연 개선 (0.2.2)

이전 버전은 분석 영역을 창 너비의 92%에서 잘랐고, 직접 말풍선 탐색에도 70% 폭 제한이 있었습니다. 거의 전체 너비를 차지하는 수신 메시지가 이 경계에 닿으면 그룹에서 제외됐습니다. 0.2.2는 오른쪽 가장자리 여백까지 분석해 긴 흰색 말풍선 전체를 가립니다. 왼쪽 정렬/프로필 그룹 조건은 유지하고, 넓은 노란색 발신 말풍선은 제외합니다.

스크롤 때는 현재 프레임에서 프로필과 메시지 위치를 다시 찾되 **닉네임 이미지가 정확히 같으면** 이전 OCR 결과를 메모리에서 재사용합니다. 화면의 과거 좌표나 같은 프로필 사진만으로 발신자를 추정하지 않습니다. 글자 이미지가 달라지면 새 OCR이 필요합니다. 신뢰도 80 이상인 단일 인식 결과만 최대 256개 보관하고 프로그램 종료 시 사라집니다.

이전 프레임의 느린 OCR이 남아 있어도 이미 읽은 이름의 가림막은 먼저 표시합니다. 새 화면을 요청하면 오래된 작업은 현재 이름 처리 후 중단하며, 스크롤의 모든 중간 프레임을 작업 큐에 쌓지 않습니다. 결과 적용 직전에는 여전히 최신 화면과 좌표가 일치하는지 검사합니다. 스크롤 중 화면이 계속 변하면 오래된 위치에 가림막을 두지 않으므로 잠깐 노출될 수 있습니다. 이름/프로필이 화면 밖이거나 새 글꼴·배율·테마로 바뀌면 캐시를 쓸 수 없고 새 인식을 기다립니다.

별도 설정 없이 적용됩니다. 기존 EXE를 종료한 뒤 소스를 새로 받아 설치·빌드하고 창 제목 **0.2.2**를 확인하세요. 기존 `intervalMs` 설정은 호환용으로 보존하며, 현재 재표시는 이 값의 고정 대기 대신 화면 변경과 작업 완료에 따라 진행됩니다.

개발 환경의 1917×820 합성 화면에서 분석 시간은 최초 OCR 약 533ms, 닉네임 캐시를 이용한 스크롤 재분석 중앙값 약 40ms였습니다. 캐시 재분석은 추가 OCR 프로세스를 실행하지 않았습니다. **Windows 화면 캡처·가림막 생성 시간은 제외한 측정이며 실제 PC 속도를 보장하는 수치가 아닙니다.** 다음 명령으로 합성 벤치마크를 실행할 수 있습니다(Tesseract 영어 데이터 필요).

```powershell
.\.venv\Scripts\python.exe scripts\benchmark-scroll.py
```

## 인식되는데 가림막이 안 보일 때 (0.2.1 이후)

0.2.0에서는 Windows 레이어 창의 불투명도를 초기화하지 않고 숨긴 Tk 창을 네이티브 API로만 표시했습니다. 그 결과 감지한 영역 수가 있어도 창이 그려지지 않을 수 있었습니다. 0.2.1은 불투명도를 255로 초기화하고 Tk 표시 상태와 Windows 표시 상태를 맞춘 뒤 다시 그립니다. 표시/불투명도/좌표 검사 실패 시 오류를 표시합니다. 화면이 그대로인 동안에는 정상 표시된 가림막을 유지하며 같은 화면을 재인식하느라 반복 제거하지 않습니다.

1. 실행 중인 필터를 종료하고 최신 소스를 다시 빌드합니다. 창 제목이 **0.2.2**인지 확인하세요.
2. **가림막 표시 테스트**를 누르면 설정 창 위에 ‘숨긴 메시지입니다’ 가림막이 8초 동안 나타납니다. 카카오톡이나 OCR 없이 실행할 수 있습니다.
3. 테스트가 보이면 기존 이름/방 설정을 적용하고 카카오톡 창을 앞으로 가져옵니다. 상태 줄은 감지 개수와 Windows 표시 상태를 확인한 개수를 나누어 표시합니다.
4. 테스트도 안 보이거나 오류 창이 나오면 해당 오류 내용을 확인하세요.

실제 채팅용 가림막은 캡처에서 제외하므로 스크린샷에는 보이지 않는 것이 정상입니다. 합성 테스트 가림막은 화면 공유로 진단할 수 있도록 캡처에도 표시합니다. 실제 눈으로 보는 화면과 캡처 결과를 구분하세요.

Windows 전용 검사는 숨김 상태 해제, 불투명도, 좌표, 포커스 유지, 캡처 제외 설정과 실제 화면 픽셀을 검사하도록 보강했습니다. Linux 개발 환경에서는 이 네이티브 검사들을 실행할 수 없으며 실제 Windows 검증이 필요합니다.

## 가림막 0개 / 대상 이름 0일 때 (0.2.0 이후)

프로필 그룹이 있는데 `대상 이름 0 / 이름 인식 실패 0`이면 OCR이 이름을 다른 문자열로 읽었을 수 있습니다. 설정 화면의 이름이 맞아도 OCR 결과에 공백이나 다른 글자가 들어가면 정확 일치 비교에 실패합니다. 이번 버전은 한글 토큰 사이의 작은 픽셀 간격을 재조합하며 충분히 큰 단어 간격은 보존합니다. 다른 글자의 유사도 매칭이나 신뢰도 기준 완화는 하지 않습니다.

1. 창 제목이 **Kakao Message Filter 0.2.2**인지 확인합니다. 소스를 새로 받아도 이전 EXE는 바뀌지 않으므로 EXE 사용자는 다시 빌드해야 합니다.
2. **OCR 닉네임 확인**을 체크하고 카카오톡 창을 앞으로 가져옵니다.
3. 잠시 기다린 뒤 필터 설정 창으로 돌아와 **인식 이름 보기 / 추가**를 누릅니다. OCR이 실제로 읽은 닉네임, 신뢰도, 위에서부터의 위치, 숨김 목록 일치 여부가 표시됩니다. 따옴표는 공백을 보여주기 위한 표시이며 이름의 일부가 아닙니다.
4. 실제 숨기려는 사람의 줄인지 확인한 뒤 **선택한 인식 이름을 숨김 목록에 추가**를 누릅니다. 기존 이름은 그대로 두고 OCR이 읽은 이름을 추가합니다. 동일하게 읽히는 다른 참여자가 있으면 함께 가려질 수 있으니 추가하지 마세요.
5. **설정 저장 및 적용**을 누른 뒤 카카오톡을 앞으로 가져옵니다. 추가 이름도 신뢰도 80 이상일 때만 매칭됩니다.

닉네임 확인은 기본 꺼짐입니다. 켠 동안의 결과만 메모리에 유지하고, 끄면 지웁니다. 결과를 로그로 저장하거나 외부로 보내지 않습니다. 사용자가 숨김 목록에 직접 추가한 이름은 일반 숨김 설정으로 저장됩니다. 인식한 실제 닉네임을 확인하기 전에는 이 화면의 원인이 공백인지 다른 글자 오인식인지 확정할 수 없습니다.

## 사진과 연속 메시지가 가려지지 않던 문제 수정

이전 버전은 이름 바로 아래의 흰색 말풍선만 검사해, 첫 메시지가 사진이거나 다음 메시지에 이름이 생략되면 놓쳤습니다. 현재 버전은 왼쪽 프로필과 발신자 이름으로 메시지 그룹을 찾고 다음 프로필 직전까지의 사진/연속 말풍선을 연결합니다. 다음 사람의 이름을 읽지 못해도 프로필이 발견되면 이전 그룹을 끊습니다. 화면 밖으로 사라진 프로필이나 이전 프레임의 발신자는 추측해서 이어 붙이지 않습니다.

이전 버전을 실행 중이면 종료한 뒤 위 ZIP을 새로 받아 압축을 풀고 해당 폴더에서 실행하세요. 설정은 기존 `%LOCALAPPDATA%` 위치를 그대로 사용합니다. 이름에 `정민욱`처럼 실제 닉네임을 정확히 입력하고 **사진 등 같은 발신자 그룹의 미디어도 가리기**를 켠 뒤 저장하세요.

상태 줄의 `발신자 그룹 / 대상 이름 / 이름 인식 실패`는 화면 내용 없이 집계한 숫자입니다. 그룹이 0이면 프로필/배경 탐색, 대상 이름이 0이면 닉네임 인식·일치 여부를 점검할 수 있습니다. 이 수정은 작은 한국어 이름, 사진 뒤 연속 메시지, 좁은 창과 최대화 배치를 재현한 합성 이미지로 검증했습니다. 사용자가 올린 실제 화면이나 실제 Windows 카카오톡에서의 성공을 검증한 것은 아닙니다.

## Windows에서 실행

1. Windows 10 **2004 이상** 또는 Windows 11에 [Python](https://www.python.org/downloads/windows/) 3.11 이상을 설치합니다. Tcl/Tk와 Python Launcher를 포함하세요. 64비트 Python 3.12를 권장합니다.
2. [Tesseract 안내](https://tesseract-ocr.github.io/tessdoc/Installation.html)의 Windows 설치 링크로 OCR 엔진을 설치하고 **Korean 및 English** 언어 데이터를 선택합니다. 기본 설치 위치 `C:\Program Files\Tesseract-OCR`는 자동 탐지합니다. 다른 위치라면 PATH에 추가하거나 설정 JSON의 `tesseractPath`에 실행 파일 경로를 지정하세요. 엔진/언어 데이터는 EXE에 포함하지 않습니다.
3. 이 저장소 폴더에서 PowerShell을 열고 실행합니다.

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\setup-windows.ps1
.\.venv\Scripts\python.exe -m kakao_filter
```

설치 스크립트는 로컬 Python 가상환경을 만들고 패키지를 설치한 뒤 OCR을 진단합니다. `ExecutionPolicy Bypass`는 이 스크립트 실행에만 적용되며 시스템 정책은 변경하지 않습니다. 회사 정책으로 금지된 경우 README의 pip 명령을 직접 실행하세요.

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m pip install --no-deps -e .
.\.venv\Scripts\python.exe -m kakao_filter --doctor
```

## 사용 방법

1. 카카오톡을 실행하고 **독립된 채팅창**을 엽니다. 기본 밝은 테마와 100% 배율에서 먼저 시험하세요.
2. 필터에서 `카카오톡 창 새로 찾기`를 누르고 대상 창을 선택합니다. 실행 파일 이름이 `KakaoTalk.exe`인 창만 나옵니다.
3. 숨길 닉네임을 한 줄에 하나씩 입력합니다. 동명이인이 있으면 사용하지 마세요. OCR은 실제 계정 ID를 알 수 없습니다.
4. `현재 선택 창 제목을 목록에 추가`를 누릅니다. 특정 방 모드에서는 **선택한 창 핸들 및 저장된 제목**이 모두 일치해야 합니다. 모든 창 옵션은 단체방/개인방을 구별하지 않습니다.
5. 상단 제목 영역과 하단 입력 영역을 제외할 높이를 조절합니다. 이 값은 DPI 인식 후 실제 픽셀 기준입니다. 잘못 설정하면 이름을 놓치거나 입력 영역을 분석할 수 있습니다.
6. 표시 방식을 선택하고 필터를 켠 뒤 `설정 저장 및 적용`을 누릅니다. 카카오톡 채팅창을 전면으로 가져옵니다.
7. 중지하려면 필터 설정 창으로 돌아가 체크를 끄세요. 창이 전면에서 사라지거나 최소화되면 가림막을 제거합니다. 종료 시에도 제거합니다.

기본 상태는 꺼짐이며 대상 미설정 상태에서는 시작하지 않습니다. Windows 시작 시 실행은 현재 사용자 Run 레지스트리에만 등록하며 체크 해제 후 저장하면 제거합니다. 소스/가상환경 위치를 옮기기 전 자동 실행을 해제하세요. 완전 가림은 `opaque`, 안내문은 `placeholder`, 흐림은 `blur`입니다. 흐림은 글자를 추측할 수 있으므로 기본 완전 가림을 권장합니다.

| 흰색 수신 말풍선 + 바로 위 닉네임 | 휴리스틱 인식 구현, 실제 카카오톡 미검증 |
| 완전 가림 / 안내문 / 흐림 | Win32 가림막 구현, 실제 PC 시험 필요 |
| 이동·크기 변경·전면 창 전환 | 약 30ms 간격으로 확인(처리 시간 추가), 기존 가림막 제거 |
| 스크롤·새 메시지 | 표시 중 프레임 변화 감지 시 제거, OCR 결과 적용 직전 원본 프레임 일치 확인 |
| 한국어 / 영어 OCR | 합성 이미지 통합 테스트 통과 |
| 연속 메시지의 생략된 이름 | 같은 프레임의 프로필 기반 그룹으로 연결, 프로필이 화면 밖이면 미처리 |
| 사진·이모티콘 | 프로필 기반의 왼쪽 정렬 영역 탐색 구현, 복잡한 투명 이미지/테마는 누락 가능 |
| 답장·어두운 테마 | 미검증, 정확한 메시지 범위 판별 보장 없음 |
| 동명이인 구별 | 미지원, 동일 표시 이름이면 구별 불가 |
| Android | 미구현 |

OCR 신뢰도 80 이상과 정규화된 이름의 정확 일치만 사용하며 유사 문자열은 매칭하지 않습니다. 닉네임은 NFC 정규화, 앞뒤 공백 제거, 연속 공백 축약을 적용합니다. OCR의 겹친 한국어 음절 토큰은 이어 붙입니다. 그래도 인식 오류는 가능하고 이름 길이가 약 260px를 넘으면 누락될 수 있습니다. OCR 신뢰도는 신원 인증이 아닙니다.

캡처는 전면 카카오톡 창의 클라이언트 영역을 로컬 화면에서 읽는 방식입니다. 다른 창/알림이 덮으면 인식이 실패할 수 있고 특수 렌더링, 원격 데스크톱, 권한 차이, 업데이트, 배율에 따라 동작이 달라집니다. 가림막은 `WDA_EXCLUDEFROMCAPTURE`를 설정하며 실패하면 필터를 중지합니다. 클릭 통과 및 포커스 비활성 스타일을 적용합니다.

**순간 노출을 막을 수 없습니다.** OCR 도중에는 이전 가림막을 지우며 새 화면의 인식이 완료될 때까지 내용이 보입니다. 애니메이션/시계 등 픽셀 변화가 잦으면 안전한 결과를 얻지 못해 가림막이 표시되지 않을 수 있습니다. 프로필 그룹과 직접 말풍선 경로별로 경로별 최대 60개 후보를 순차 분석하므로 긴 방에서는 지연이 커질 수 있습니다. 보안/비밀 보호 수단으로 사용하지 마세요.

`hideImages` 또는 UI의 미디어 가리기 옵션을 켜면 같은 발신자 그룹의 사진 등도 가립니다. 끄면 대부분이 흰색인 말풍선만 가립니다. 화면 색상 기반 휴리스틱이므로 흰 배경 사진과 말풍선을 완벽히 구별할 수는 없습니다.

## 개인정보와 설정

설정 파일은 `%LOCALAPPDATA%\KakaoMessageFilter\settings.json`에 저장됩니다. 설정 파일에는 닉네임, 채팅방 제목, 옵션과 OCR 경로만 저장됩니다. 전체 캡처는 메모리에서 처리하고 외부 API를 호출하지 않습니다. pytesseract CLI 실행 과정에서 닉네임 조각과 인식 출력이 운영체제 임시 파일로 만들어졌다가 정상 종료 시 삭제될 수 있습니다. 채팅 전체 화면이나 메시지 로그를 영구 저장하지 않습니다. 패키지/OCR 설치 때는 다운로드 네트워크가 필요합니다. 설정은 평문이므로 민감한 닉네임과 방 제목을 넣는 점에 유의하세요.

손상된 설정은 덮어쓰지 않고 오류를 표시합니다. 다음 저장은 사용자가 입력한 새 설정으로 교체합니다. 설정은 임시 파일 작성 후 원자적으로 교체합니다.

## 개발 및 테스트

```bash
python -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m pip install -e '.[dev]'
.venv/bin/python -m kakao_filter --doctor
.venv/bin/python -m pytest -q
```

Linux에는 `tesseract-ocr`, `tesseract-ocr-kor`, `fonts-noto-cjk`가 필요합니다. Windows에서는 `.venv\Scripts\python.exe`를 사용하세요. Linux는 GUI 실시간 실행 대상이 아니며 `--doctor`와 코어 테스트만 지원합니다. 한국어 테스트는 지정된 Noto CJK 글꼴이 있는 환경에서 실행하며 글꼴이 없으면 건너뜁니다. Win32 테스트는 Windows에서만 실행합니다.

검사는 설정 유효성/보존, 방 범위, 잘못된 사용자 매칭 방지, 낮은 신뢰도/모호한 이름 무시, 프로필 없는 연속 메시지 무시, 프로필이 있는 사진·연속 메시지 연결, 다음/잘린 프로필에서 그룹 종료, 12px 한국어 닉네임 OCR, 실제 한국어/영어 OCR, 오래된 프레임 거부를 포함합니다. `.github/workflows/check.yml`은 Linux 테스트와 Windows 네이티브 스타일/캡처 제외 검사를 실행하고 EXE를 아티팩트로 만듭니다. 이 워크플로 자체는 클라우드 작업에서 실행하지 않았습니다.

## EXE 만들기

Windows에서 설치를 마친 뒤 실행합니다. Linux에서는 Windows EXE를 만들지 않습니다.

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\build-windows.ps1
```

출력은 `dist\KakaoMessageFilter.exe`이며 Tesseract를 별도로 설치해야 합니다. CI가 실행되면 `KakaoMessageFilter-Windows` 아티팩트에서도 받을 수 있습니다. 현재 작업에서 Windows EXE 빌드나 코드 서명은 수행하지 않았습니다.

## 실제 PC 확인 항목

- [ ] 테스트 방에서 대상/비대상 닉네임 각각의 말풍선을 확인한다.
- [ ] 동명이인, 긴 이름, 줄바꿈, 연속 메시지가 잘못 연결되지 않는지 확인한다.
- [ ] 스크롤, 새 메시지, 창 이동/크기 변경 직후 오래된 위치에 남지 않는지 확인한다.
- [ ] 다중 모니터와 100/125/150% 배율에서 좌표를 확인한다.
- [ ] 가림막 위 클릭·드래그·휠이 카카오톡으로 전달되는지 확인한다.
- [ ] 앱 전환·최소화·필터 OFF·종료 후 가림막이 제거되는지 확인한다.
- [ ] 로그인 자동 실행 등록/해제와 OCR 설치 오류 동작을 확인한다.

## 파일 구성

- `kakao_filter/app.py`: 설정 UI, 최신 프레임 확인, 비동기 OCR
- `kakao_filter/pipeline.py`: 캐시 기반 즉시 재표시, 최신 프레임 작업 관리와 오래된 작업 중단
- `kakao_filter/windows.py`: 프로세스/창 탐색, DPI, Win32 스타일, 자동 실행
- `kakao_filter/detector.py`: 프로필/사진/연속 말풍선 그룹 탐색, 닉네임 OCR 및 정확 매칭
- `kakao_filter/overlay.py`: 클릭 통과 가림막, 안내문, 흐림
- `kakao_filter/config.py`: 설정 검증과 원자적 저장
- `tests/`: 인식·설정·프레임·Windows 네이티브 검사
