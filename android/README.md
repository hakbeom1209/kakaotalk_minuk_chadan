# 카카오 메시지 필터 · Android 0.1.0

Android 8.0(API 26) 이상을 대상으로 만든 **접근성 기반 시제품**입니다. PC와 같은 숨김 목록/채팅방 설정을 사용하지만 Android의 접근성 서비스와 가림막으로 별도 구현했습니다. 카카오톡 내부 파일이나 서버 메시지를 바꾸지 않습니다.

**실제 카카오톡 기기에서의 호환성은 아직 검증하지 않았습니다.** 카카오톡이 접근성에 발신자·메시지 위치를 제공해야 작동합니다. 정보가 없으면 추측해서 가리지 않으며 현재 버전에는 OCR/화면 캡처 대체 경로가 없습니다.

## APK 설치

[Android 테스트 APK 다운로드](https://github.com/hakbeom1209/kakaotalk_minuk_chadan/raw/refs/heads/main/android/downloads/KakaoMessageFilter-Android-debug.apk)

1. 휴대폰에서 APK를 받아 엽니다. 요청되면 다운로드에 사용한 브라우저/파일 앱의 **출처를 알 수 없는 앱 설치**를 허용합니다.
2. 앱을 열고 안내를 읽은 뒤 **동의하고 접근성 설정 열기**를 누릅니다.
3. 시스템 접근성 설정의 설치된 앱/서비스에서 **카카오 메시지 필터**를 켭니다. Android 13 이상에서 켤 수 없으면 앱 정보의 메뉴에서 **제한된 설정 허용**을 확인하세요. 메뉴 이름/위치는 제조사마다 다릅니다.
4. 앱으로 돌아와 **가림막 표시 테스트**를 눌러 5초 동안 가림막이 보이는지 확인합니다.
5. 숨길 닉네임을 정확히 입력합니다. 먼저 테스트용 채팅방에서 시험하세요. 닉네임이 같은 사람은 구별할 수 없습니다.
6. 적용할 채팅방 제목을 입력하거나 **모든 카카오톡 채팅방에 적용**을 선택합니다. 모든 방 옵션은 개인방도 포함합니다.
7. **필터 켜기 → 설정 저장 및 적용**을 누르고 카카오톡의 대화방을 엽니다.
8. 잠시 뒤 앱으로 돌아오면 **마지막 채팅 화면의 발신자/대상/가림막 개수**를 확인할 수 있습니다. 필터를 끄려면 **지금 필터 중지**를 누르거나 시스템 접근성 권한을 끄세요.

APK는 개발용 debug 키로 서명한 테스트 빌드입니다. Google Play에 게시한 정식 앱은 아닙니다. 개발자가 다른 키로 만든 APK로 교체하면 업데이트 설치가 거부될 수 있습니다. 이때 기존 설정을 JSON으로 내보낸 뒤 기존 앱 제거/새 설치/설정 가져오기를 진행하세요. 키를 무시하도록 서명 검증을 우회하지 마세요.

## 현재 구현

- 숨김 닉네임 목록, 정확 일치/NFC 정규화, 방 제목 범위, 켜기/끄기
- 접근성에 노출된 프로필/발신자를 기준으로 같은 프레임의 메시지 그룹 판별
- 사진·이모티콘과 이름이 생략된 연속 메시지 연결
- 다음 프로필에서 그룹 종료: 이름을 읽지 못한 다음 프로필도 경계로 사용
- 가로로 긴 메시지를 화면의 고정 비율로 자르지 않고 전체 좌표 사용
- 클릭·스크롤이 통과되는 완전 가림/안내문
- 스크롤·내용 변경 이벤트에 맞춘 갱신, 다른 앱 전환/화면 꺼짐/잠금 시 제거
- 화면에 좌표가 없는 이전 프레임의 발신자나 메시지 위치를 이어 붙이지 않음
- PC JSON 설정 가져오기/내보내기

접근성 가림막(`TYPE_ACCESSIBILITY_OVERLAY`)을 사용하므로 **별도 ‘다른 앱 위에 표시’ 권한은 필요하지 않습니다.** 화면 녹화/사진·파일 접근/인터넷 권한도 요청하지 않습니다. 완전 가림은 불투명하게 그립니다. Android 12의 일반 앱 오버레이 터치 제한을 피하려고 불투명도를 낮추는 방식은 사용하지 않습니다.

## 한계와 확인 방법

- 발신자 0: 접근성 이름/프로필 정보가 없거나, 현재 화면 구조가 지원하는 형태와 다를 수 있습니다. 특정 카카오톡 버전에서 동작을 보장하지 않습니다.
- 대상 0: 실제 접근성 이름이 숨김 목록과 다르거나 선택한 방 제목을 확인하지 못했을 수 있습니다. 이름을 정확히 입력하고 테스트 방에서 범위를 확인하세요.
- 가림막 0: 접근성에서 메시지 영역을 찾지 못했거나 지원하지 않는 배치일 수 있습니다.
- 채팅 입력창이 보이는 대화방에서만 처리합니다. 친구/채팅방 목록을 가리지 않도록 입력창 확인을 요구합니다.
- 이름/프로필이 화면 위로 사라진 메시지는 소유자를 추측하지 않습니다.
- 사진·답장·이모티콘 등의 접근성 구조는 버전마다 달라 누락 또는 영역 오차가 있을 수 있습니다. 복잡한 답장/테마/팝업/분할 화면은 기기 검증이 필요합니다.
- 스크롤 중 잠깐 노출될 수 있습니다. 메시지를 한순간도 볼 수 없게 하는 보안 도구는 아닙니다.
- 흐림은 미구현입니다. PC JSON의 `blur`를 가져오면 완전 가림으로 바꿉니다.
- 실제 Android 기기/에뮬레이터와 카카오톡 계정에서의 동작 검사는 이 클라우드에서 실행하지 않았습니다.

## 개인정보

서비스는 카카오톡이 전면에 있을 때만 그 앱의 접근성 트리를 읽습니다. 메시지 내용은 화면 구조를 판별하는 동안 메모리에서만 사용하고 저장·로그·외부 전송하지 않습니다. 다른 앱은 전면 패키지 이름만 확인하고 대화 트리를 읽지 않습니다. 통계 화면에는 개수와 상태만 표시합니다.

설정의 닉네임/방 제목은 앱 내부 SharedPreferences에 평문 JSON으로 저장됩니다. 자동 백업은 끄며 삭제하면 설정도 사라집니다. 사용자가 내보내기를 요청한 JSON에는 숨김 목록과 옵션이 포함됩니다. 파일을 안전하게 보관하세요. 가져온 설정은 필터 OFF 상태로 적용하며 내용을 확인한 후 직접 켜야 합니다.

## 소스 빌드

Android Studio에서 이 `android` 폴더를 열면 됩니다. JDK 17 또는 21, Android SDK Platform 35 및 Build Tools 35.0.0이 필요합니다. 사용한 도구는 AGP 8.9.2 / Kotlin 2.1.20 / Gradle 8.11.1 / JDK 21입니다. Gradle Wrapper에 배포 ZIP의 SHA-256 검증을 설정했습니다.

Windows PowerShell:

```powershell
cd android
.\gradlew.bat :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
```

Linux/macOS:

```sh
cd android
./gradlew :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
```

SDK 경로는 Android Studio가 만든 `local.properties` 또는 `ANDROID_HOME`으로 설정하세요. `local.properties`, 빌드 캐시, 서명 키는 저장소에 넣지 않습니다.

출력: `app/build/outputs/apk/debug/app-debug.apk`

## 검증 범위

JVM 단위 테스트는 발신자/사진/연속 메시지 연결, 읽지 못한 프로필 경계, 다른 사람의 본문에 포함된 닉네임, 넓은 메시지, 방 범위, 필터 OFF, 편집 입력/명시된 발신 메시지 제외, 현재 스크롤 좌표를 검사합니다. 빌드와 Android Lint는 Android API/리소스/매니페스트 구성도 검사합니다. 이 검증이 실제 카카오톡 접근성 호환성을 입증하지는 않습니다.

실제 기기에서는 다음을 확인하세요.

- [ ] 대상/비대상, 동명이인, 사진·이모티콘·답장·긴 메시지
- [ ] 스크롤·방 전환·가로/세로 회전 후 좌표
- [ ] 가림막 위 클릭·휠/스와이프·메시지 입력
- [ ] 다른 앱·친구 목록·잠금 화면에서 가림막 제거
- [ ] 필터 OFF/접근성 권한 해제 후 제거
- [ ] PC JSON 가져오기/내보내기와 앱 업데이트
